# Distance Ke Beech 💗

A single-file, mobile-friendly Truth or Dare game for couples in a long-distance relationship.

## Play online

https://kaivalyajoshi20.github.io/distance-ke-beech/

## Deploy

The site is deployed with GitHub Pages using the workflow in `.github/workflows/pages.yml`. Pushes to `main` trigger a deployment. In repository Settings → Pages, select **GitHub Actions** as the build and deployment source.

## Run locally

Open `index.html` in a modern browser. No build step is required.
